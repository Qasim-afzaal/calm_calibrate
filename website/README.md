# CalmCalibrate website

Static landing page + privacy policy for App Store / Play Store URLs.

**Live:** https://calm-calibrate.vercel.app

| Page | URL |
|------|-----|
| Landing / Support / Marketing | https://calm-calibrate.vercel.app |
| Privacy Policy | https://calm-calibrate.vercel.app/privacy |

## Deploy

```bash
cd website
npx vercel deploy --prod
```

Update App Store / Google Play store links in `index.html` when listings are live.
